✓

Trivial and failed VCs are dropped entirely, not averaged in. A trivial VC (Flux/VC/<Name>.lean's final def is literally True — generated boilerplate with no real proof obligation) would otherwise pad the VC count with near-zero-cost records and quietly pull every mean toward zero. A failed VC is worse: if a proof errors mid-computation — e.g. hitting maxRecDepth deep inside predicate abstraction — the exception escapes before benchPhase's own print statement runs, so its record is missing whichever phases never finished. Mixing that partial record in alongside fully-solved VCs would understate PA/discharge without saying so.

1,041 of 1,924 generated VCs (54%) are trivial and 42 (2.2%) failed, both matching this repo's own Table 1/Table 2 counts (regenerable via make_table.py) VC-for-VC. Every number on this page is computed over the remaining 841 non-trivial, solved VCs only.

How the buckets are computed

Every phase below is timed by benchPhase (Flex/Tactic/Utils.lean), gated by flex.benchPhases, emitting [phase] <tac>:<phase>=<hb> ms=<ms> into the build log.

zap fusion:sol + fusion:build + fusion:clean + solve_fixpoint:fuse
simp top:simp
PA solve_fixpoint:pa
discharge solve_fixpoint:close

The no-cyclic-κ / has-cyclic-κ split reuses this repo's existing κ-classification (none / acyclic_only / cyclic_only / both, from [fusion] Start/End κ: log lines — the same classification behind Table 2's kvar breakdown): none/acyclic_only → no cyclic κ, cyclic_only/both → has cyclic κ.

Source: eval_benchmarks/rq3_table/rq3_phase_table.py, reading the rebuilt *.log files for all four suites. flux-medium aggregates flux-demo, kani-vecdeque and pldi23. Reproduce with python3 scripts/rq3_instrument_phases.py && python3 eval_benchmarks/rq3_table/rq3_phase_table.py.
